# ✨ Gerador de Nomes Aleatórios: A Sorte Decide, Você Escolhe o Gênero! ✨

**Já se perguntou qual seria o nome perfeito para aquele personagem épico, seu futuro filho ou até mesmo seu novo pet?** 🤔 Não se preocupe, a gente também! E foi assim que nasceu este incrível gerador de nomes aleatórios. Prepare-se para ser surpreendido pela combinação de criatividade e sorte!

## 🔮 Como Funciona a Mágica?

Este não é um gerador de nomes comum. Aqui, a sorte assume o controle, mas você tem o poder de definir o gênero. Escolha entre:

*   **👦 Menino:** Prepare-se para nomes que soam fortes, clássicos e cheios de energia.
*   **👧 Menina:** Deixe-se levar pela delicadeza, elegância e sonoridade dos nomes femininos.
*   **🐾 Pet:** Encontre nomes que combinem com a fofura, alegria e singularidade do seu companheiro de quatro patas.

## 💡 Recursos que Tornam Tudo Mais Divertido:

*   **✨ Animação ao Gerar:** Um mini spinner hipnotizante para te fazer esperar (quase) pacientemente pelo seu nome perfeito.
*   **📋 Copiar com Um Clique:** Aquele nome incrível? Copie e cole em qualquer lugar com um simples toque.
*   **🚀 Compartilhar Facilmente:** Espalhe a novidade no WhatsApp, Facebook e Twitter com mensagens personalizadas.
*   **🎨 Cores Vivas e Temáticas:** A cor de fundo muda conforme o gênero escolhido, para uma experiência visual imersiva.
*   **🔤 Sopa de Letrinhas:** Uma lista com todas as letras do alfabeto para você ter uma predefinição na busca por nomes.
*   **🎨 Minimalista:** Um design clean e agradável para uma experiência única.
